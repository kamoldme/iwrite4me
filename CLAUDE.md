# iWrite Tool

## gstack

Use the `/browse` skill from gstack for all web browsing. Never use `mcp__claude-in-chrome__*` tools.

### Available gstack skills
- `/plan-ceo-review` — CEO-level plan review
- `/plan-eng-review` — Engineering plan review
- `/frontend-design` — Frontend design command for production-grade UI work and attached image style imitation
- `/frontend design` — Alias for `/frontend-design`
- `/review` — Code review
- `/ship` — Ship code
- `/browse` — Headless browser for QA, testing, and web browsing
- `/qa` — QA testing
- `/setup-browser-cookies` — Set up browser cookies for authenticated browsing
- `/retro` — Retrospective
